# 미스터리 역사 박물관 (Mystery History Museum)

『8번 출구』 형식을 빌린 **초등학교 5학년 사회 2학기 1단원 「유적과 유물로 살펴본 옛 사람들의 생활」** 복습 게임입니다.

끝없이 반복되는 어두운 박물관 전시실에서, 교과서 내용과 **사실이 다른 전시(이상 현상)** 를 찾아내야 합니다.

## 규칙

- 이상한 전시를 하나도 놓치지 마세요.
- 이상한 전시를 발견하면 **즉시 되돌아가세요.**
- 이상한 전시가 없다면 **앞으로 나아가세요.**
- 제8 전시실을 지나 출구로 나가세요.

틀리면 제0 전시실로 돌아갑니다. 판단할 때마다 무엇이 이상했는지(또는 정상이었는지)와 **교과서 속 사실**이 기록 카드로 나옵니다.

## 조작

| 기기 | 걷기 | 둘러보기 | 뒤돌기 | 자세히 보기 |
|---|---|---|---|---|
| 스마트패드/폰 | ▲ ▼ 버튼 | 화면 끌기 | ⟲ 버튼 | 전시물 누르기 |
| PC | W/S, ↑/↓ (Shift 빨리 걷기) | 마우스 끌기, A/D, ←/→ | Space | 전시물 클릭 |

## 구성

- 전시물 14개(유물 진열장 6, 고분 벽화, 고인돌, 설명 패널 6) + 떠도는 해설사
- 이상 현상 41개 — 모두 교과서 핵심 내용을 바꾼 것 (시대 바꾸기, 인물 바꾸기, 설명 바꾸기, 그림 바꾸기)
- 한 번 발견한 이상 현상은 모두 찾을 때까지 다시 나오지 않습니다. (원작과 동일)
- 첫 탈출 후에는 입구 안내판에 **아직 발견하지 못한 이상 현상 수**가 표시됩니다.
- 이상 현상 기록장: 발견한 것은 정답과 함께, 못 찾은 것은 어느 전시물인지 힌트로 표시

## 기술

- 3D: [three.js](https://threejs.org/) r149 (vendor 폴더에 포함) — 저폴리곤 + 캔버스 텍스처라 스마트패드에서도 가볍게 동작
- 외부 이미지·소리 파일 없이 동작 (그림은 캔버스로, 소리는 Web Audio로 생성)
- 해설사 음성은 기기의 한국어 TTS 사용 (메뉴에서 끌 수 있음)
- 기록은 브라우저 localStorage에 저장

## 교사용

- 주소 뒤에 `?test=이상현상ID` 를 붙이면 첫 전시실에 그 이상 현상이 나옵니다. (ID는 `js/data.js` 참고)
  - 예: `?test=celadon_white`
- 전시물·이상 현상 내용은 `js/data.js` 한 파일에서 고칠 수 있습니다.
- 그림을 실제 이미지로 바꾸려면 [ASSETS.md](ASSETS.md) 를 참고하세요.
